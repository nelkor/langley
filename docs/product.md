# Product

## Назначение

Langley — веб-приложение для тренировки иностранных слов.

Пользователь выбирает языковую пару и один или несколько наборов слов,
после чего запускает бесконечную тренировку карточек. Слова, которые
пользователь знает лучше, должны появляться реже. Слова, которые пользователь
знает хуже, должны появляться чаще.

## Пользовательский сценарий

### 1. Вход в приложение

При открытии приложения пользователь попадает на экран настройки тренировки.

На этом экране он имеет возможность:

- выбрать родной язык;
- выбрать изучаемый язык;
- выбрать один или несколько доступных наборов слов;
- запустить тренировку.

Можно запустить тренировку, только если выбран хотя бы один набор слов.

### 2. Начало тренировки

После запуска тренировки приложение формирует
рабочую выборку из доступных слов выбранных наборов.

В тренировку попадают только слова, которые:

- входят хотя бы в один выбранный набор;
- имеют значение на изучаемом языке;
- имеют значение на родном языке.

Если одно и то же слово входит в несколько наборов,
оно не дублируется в итоговой выборке.

### 3. Ход тренировки

В любой момент тренировки пользователь видит на экране текущую карточку.
На карточке написано слово на родном языке. Карточку можно переворачивать,
на обратной стороне написано слово на изучаемом языке.

Для текущей карточки пользователь выбирает, хорошо ли он знает это слово.
После этой оценки карточка уходит, и приходит следующая.

### 4. Очередь слов

Хорошо знакомые пользователю слова встают в конец очереди.

Плохо знакомые слова должны приходить чаще:
они добавляются случайным образом в один из ведущих сегментов очереди.

## Наборы слов

Наборы слов зашиты в клиентское приложение,
но доступ к ним имитирует запрос к серверу.

Можно получить:

- поддерживаемые языки;
- список наборов слов, подходящих под выбранные языки;
- итоговый набор слов из выбранных наборов.
